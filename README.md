# Milady Skills

Official agent skills for the [Milady](https://github.com/milady-ai/milady) AI assistant.

## Install

```bash
# Via the Milady Skills UI marketplace (built-in)
# Or via npx skills CLI:
npx skills add milady-ai/skills/bags
npx skills add milady-ai/skills/binance-spot
```

## Available Skills

| Skill | Description |
|-------|-------------|
| `bags` | Portfolio tracking and bag management |
| `moltbook` | Moltbook integration |
| `milady-development` | Milady development workflows |
| `binance-*` | 23 Binance trading/DeFi skills |

## Structure

Each skill is a directory with a `SKILL.md` file following the [Agent Skills open standard](https://github.com/anthropics/skills).

## Security

All skills in this repo are maintained by the Milady team. Community contributions are reviewed before merge.
